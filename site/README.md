# Weekkeep public site

Public product, privacy, terms, and support pages for the Weekkeep iPhone app.

## Routes

- `/` — product overview
- `/privacy` — bilingual privacy policy
- `/terms` — bilingual terms of use
- `/support` — bilingual support and contact

## Local development

```bash
npm ci
npm run dev
npm run lint
npm test
```

The site uses the same Weekkeep foundation palette and bundled LINE Seed KR fonts as the app. `public/og.png` is the social preview asset.
