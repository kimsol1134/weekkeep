# Weekkeep Remotion submission video

This is the canonical Remotion submission video project for Weekkeep Shipaton.
It is a local TypeScript project with the `WeekkeepShipaton72` composition:
1920×1080, 30fps, exactly 2160 frames / 72 seconds.

The edit uses the real English SwiftUI capture as the hero. The latest source
capture contains simulator home-screen pre-roll and a short loading handoff;
the curated edit never references either. Functioning app footage begins at
source frame 360 (12.0 seconds at the Remotion timeline rate), with the
opening and privacy primer using a separate earlier Welcome subclip. The
source capture is deliberately re-cut into the ten approved narrative scenes;
it is not played linearly. The share visual is the real in-app Story artifact.
No external share destination or native Korean share sheet is shown.

The opt-in source capture is made with the DEBUG `-ui-fixtures` launch path and
the bundled `SamplePhotoFixtures`. It is deterministic UI evidence and does
not exercise simulator PhotoKit ingestion; live PhotoKit behavior is validated
separately.

## Caption source and workflow

`src/data/audio_meta.json` is the source of truth for the approved narration
words and their timings. `src/data/caption_groups.json` is derived editorial
metadata: it keeps the spoken words verbatim while grouping them into readable
phrases and adding only short, gap-safe holds. The boundary map and timing
derivation live in `scripts/rebuild-captions.mjs`; the integrity checks live in
`scripts/validate-captions.mjs`.

When narration metadata changes, review the boundary map, then run:

```bash
npm run captions:rebuild
npm run validate:captions
npm run check
```

`npm run captions:verify` confirms that the checked-in groups still reproduce
deterministically from `audio_meta.json`. No footage, audio, screenshots, or
other source media is regenerated by this workflow.

## Asset provenance

Runtime binaries are copied into `public/` from the already-approved local
source trees. The source media is not mutated. `src/data/audio_meta.json`
retains the approved narration/BGM metadata; the phrase grouping in
`src/data/caption_groups.json` is generated from that narration source and
checked by the caption validation workflow above.
See `LICENSES.md` and `licenses/` for the retained license and provenance
record.
